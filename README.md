# Multi-Exit ResNet Implementation

## Project Structure

### Core Model & Algorithm Files
- `multi_exit_ResNet.py`: Implementation of Multi-Exit ResNet architecture with weighted exit loss
- `algo_.py`: Core algorithmic implementations with exit loss weighting functionality

### Training Pipeline
- `main.py`: Main execution script with exit loss weight configuration
- `train.py`: Training loop implementation with exit loss weights

### Data Management
- `data_preprocessing.py`: Data preprocessing and preparation utilities

### Analysis & Visualization
- `visualization_.py`: Visualization tools and algorithm analysis plots
